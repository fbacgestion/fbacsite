# FBAC — Site HTML/CSS/JS

Première version statique du site du Full Boxe Américaine Club.

## Lancer le site
Double-cliquer sur `index.html` suffit pour le tester dans un navigateur.

## Modifier les actualités
Les actualités et événements sont dans `js/script.js`.

## Ajouter de vraies photos
Place tes images dans `images/`, puis remplace les blocs `.news-image` / `.gallery-item` par des balises `<img>` ou adapte le CSS.

## Hébergement gratuit
Le site fonctionne avec GitHub Pages, Cloudflare Pages ou Netlify.
Aucun serveur PHP ou base de données n'est nécessaire pour cette première version.

## Important
Le formulaire de contact est actuellement une démo front-end. Pour recevoir réellement les messages, il faudra le connecter à un service de formulaire ou à un backend.
